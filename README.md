# 英语小站 · English Study

一个为 iPhone / iPad 设计的英语学习小工具，把「背单词、默写、语法、短语、作文、英文原著」放在同一个离线应用里。

项目是一个 [DSH](https://deepseek.com) 小工具（mini app），使用 React 18 编写，没有构建步骤和第三方运行时依赖。

## 功能

- **背单词**：70 个内置单词，4 个词库；间隔复习节奏为 1 / 3 / 7 / 21 天；支持系统英文发音和记忆阶段展示。
- **默写**：听音默写或看中文默写，支持首字母提示、即时纠错、错词回顾。
- **语法**：12 节讲解，36 道随堂练习，覆盖时态、冠词、介词、从句、非谓语、虚拟语气、倒装、比较级和连接词。
- **短语**：40 个按日常、旅行、学术、写作、情绪分类的地道表达，支持卡片和列表两种模式。
- **作文**：6 类写作模板、4 篇双语范文、4 个练笔题目；提供字数统计、结构提示、连接词自检和草稿自动保存。
- **原著**：5 篇公版英文作品选段，支持点词看释义、逐段朗读、中英译文切换、阅读进度和读后问题。
- **学习记录**：每日清单、连续学习天数、XP、近 7 天学习节奏，全部保存在本机 `localStorage`。
- **外观**：手机优先布局，适配深色模式和安全区域。

## 运行方式

这是一个 DSH 小工具，不需要 `npm install`，也不需要打包：

1. 把整个目录放到 `~/apps/english-study`。
2. 在 DSH 的「小工具」中打开「英语小站」。
3. 也可以将目录放入任意支持 JSX 的 React 18 环境，以 `App.jsx` 的默认导出作为入口。

发音由系统 `speechSynthesis` 提供，不依赖网络。

## 数据与隐私

- 学习进度、草稿和设置只写入本机 `localStorage`（键名 `english-study-v1`）。
- 没有账号、没有上传、没有第三方统计。
- 清除学习记录会删除进度和草稿，但保留设置。

## 内容说明

- 单词释义、例句、语法讲解、短语和作文均为本项目原创编写。
- 原著选段来自公版作品：Lewis Carroll、Jane Austen、Charles Dickens、Oscar Wilde、O. Henry，保留原文用词、拼写和标点。
- 项目仅用于个人英语学习，不构成任何考试机构的官方材料。
