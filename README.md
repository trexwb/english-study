# 英语小站 · English Study

一个为 iPhone / iPad 设计的英语学习小工具，把「背单词、默写、语法、短语、作文、英文原著、知识速查、题型专项」放在同一个离线应用里。

项目是一个 [DSH](https://deepseek.com) 小工具（mini app），使用 React 18 编写，没有构建步骤和第三方运行时依赖。

## 功能

- **背单词**：937 个内置单词，6 个内置词库（日常高频、四六级核心、学术进阶、原著精读、初中核心 388、高中核心 310）+ 用户录入的「我的词库」；间隔复习节奏为 1 / 3 / 7 / 21 天；列表分页加载，支持系统英文发音和记忆阶段展示。
- **录入生词**：输入一个单词即自动得到音标、释义和例句——识别链依次查内置词库、原著词表和内置词典（3583 词，覆盖中高考大纲词汇；例句取自 Tatoeba 语料与项目补写），未命中时按词根词缀给出拆解与词性推测（诚实标注「推测」）；保存进「我的词库」后自动接入学习、默写与间隔复习，支持编辑和删除。
- **默写**：听音默写或看中文默写，支持首字母提示、即时纠错、错词回顾。
- **语法**：49 节讲解，208 道随堂练习，每节按中考 / 高考标注并配 3–4 条本考段考点（共 196 条），可按教材学段（七年级 / 八年级 / 九年级 / 高中拓展）与考段筛选，覆盖时态、冠词、介词、主谓一致、被动语态、情态动词、条件句、宾语从句、定语从句、状语从句、非谓语、虚拟语气、倒装、强调、比较级和连接词。
- **短语**：344 个按日常、旅行、学术、写作、情绪、职场、社交、观点、中考固定搭配、高考动词短语、作文衔接语、话题语块、中考金句、高考金句分类的地道表达，支持卡片和列表两种模式。
- **作文**：27 类写作模板（含读后续写、概要写作、倡议书与通知、演讲稿）、19 篇双语范文、36 个练笔题目，全部标注中考 / 高考 / 通用，模板、范文、练笔三个视图都能按考段筛选；选定考段后给出「模板 → 范文 → 练笔」的起步推荐。提供字数统计、结构提示、连接词自检和草稿自动保存。
- **知识速查**：不规则动词三态表 153 条、词根词缀 126 条、易混词辨析 56 组、词性转换 230 组，可按考段与类型筛选，用于阅读时现场拆生词、语法填空时按空格造词、写作时排除错用。
- **题型专项**：语法填空 7 篇、完形填空 6 篇、七选五 6 篇、短文改错 6 篇，逐空作答与整篇解析分开呈现，答案可展开对照。
- **原著**：11 篇公版英文作品选段，支持点词看释义、逐段朗读、中英译文切换、阅读进度和读后问题。
- **学习记录**：每日清单、连续学习天数、XP、近 7 天学习节奏，全部保存在本机 `localStorage`。
- **外观**：手机优先布局，适配深色模式和安全区域。

## 内容增补方式

学习内容是纯数据数组，扩充时不直接改主文件，而是写 `epacks/*.pack` 片段（只含数组元素文本），再用
`python3 epacks/apply.py` 合并：锚点必须唯一、id 重复会自动跳过，所以脚本可以反复运行；
合并后用 `node epacks/validate.mjs` 校验字段契约，它会检查重复词条会被 `Object.fromEntries`
静默丢弃、选项文本重复会撞 React key、范文与译文段数必须一一对齐等真实故障点。

## 运行方式

这是一个 DSH 小工具，不需要 `npm install`，也不需要打包：

1. 把整个目录放到 `~/apps/english-study`。
2. 在 DSH 的「小工具」中打开「英语小站」。
3. 也可以将目录放入任意支持 JSX 的 React 18 环境，以 `App.jsx` 的默认导出作为入口。

发音由系统 `speechSynthesis` 提供，不依赖网络。

## 数据与隐私

- 学习进度、草稿和设置只写入本机 `localStorage`（键名 `english-study-v1`）。
- 自己录入的单词也存在同一个键里；清除学习记录会保留它们和设置。
- 没有账号、没有上传、没有第三方统计。

## 内容说明

- 内置词库（`data/words.js`）的单词释义、例句、语法讲解、短语和作文均为本项目原创编写。
- 内置词典（`data/dictionary.js`，3583 词）取自开源词典项目 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT 许可）中标有中考（zk）/高考（gk）的词头，音标、词性与释义由 `tools/build_dictionary.py` 从其 phonetic / pos / translation 列清洗压缩而来（释义改写为不超过 24 字的中文简义），全部数据随应用本地打包，运行期不联网。
- 词典例句（`data/examples.js`，3583 句）来自 [Tatoeba](https://tatoeba.org) 英中平行句对（句子以 CC BY 2.0 FR 许可发布），由 `tools/build_examples.py` 按词边界配句并用 OpenCC 统一为简体；Tatoeba 未能覆盖的 442 条由本项目补写（源文件入库保管在 `tools/gap-examples/`，构建时自动合并），同样只存本地。
- 不规则动词、词根词缀与易混词按中学考点整理，例句为项目原创；三态写法保留英美差异（如 `learnt / learned`），并用 `常错` 标出极易写错的动词（lie / lay、beat、hang、shine、spread）。
- 语法填空、完形填空、七选五与短文改错的全部语篇均为项目自编，不取自任何真题或教辅原文，考点分布按中考、高考两套要求设置。
- 每节语法课的考点条目、词性转换表的派生链与考法提示均为本项目按中考、高考两套要求原创整理；派生词只收标准英语常用形式，名动同形的词（help / use / practice 等）两个词性都会列出，没有常用形式的槽位显示「—」。考点条目不标注具体年份卷区，因为无法核实。
- 语法课的学段（七年级 / 八年级 / 九年级 / 高中拓展）为项目自研标注：按人教版为主、综合参考外研社、译林、仁爱四套主流初中教材的讲授进度，四套初中教材均不系统讲授、属高中体系的内容标「高中拓展」；各版本进度有差异，学段仅作学习排序参考，本项目与任何教材出版方均无官方合作。
- 原著选段来自公版作品：Lewis Carroll、Jane Austen、Charles Dickens、Oscar Wilde、O. Henry、L. Frank Baum、J. M. Barrie、Frances Hodgson Burnett、Jack London、Arthur Conan Doyle，原文取自 Project Gutenberg，保留原文用词、拼写和标点；中文译文为本项目原创。
- 项目仅用于个人英语学习，不构成任何考试机构的官方材料。
